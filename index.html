⚙️ Manajemen Data & Cadangan (Backup)

Data Anda disimpan secara aman langsung di penyimpanan browser komputer Anda (Local Storage).

📦 Backup Database (JSON)

Unduh seluruh data transaksi, saldo akun dompet, dan target anggaran dalam bentuk file .json untuk disimpan sebagai cadangan.

🔄 Pulihkan Data (Restore)

Unggah file backup .json yang telah diunduh sebelumnya untuk mengembalikan seluruh catatan keuangan Anda.

📑 Ekspor ke Spreadsheet (CSV)

Format tabel lengkap siap buka di Microsoft Excel, Google Sheets, atau aplikasi akuntansi lainnya.

⚠️ Reset ke Data Awal

Hapus perubahan Anda dan kembalikan data aplikasi ke data sampel contoh. Tindakan ini tidak dapat dibatalkan.
